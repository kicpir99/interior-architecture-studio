# Wytyczne Projektowe — Studio Architektury Wnętrz Portfolio

## Design System
Read DESIGN.md before visual or UI work: it defines the fonts (`Schibsted Grotesk`, `DM Sans`, `IBM Plex Mono`), colors (`#ECEAE4` stone background, `#F7F6F2` alabaster surface, `#161715` basalt tool slab, `#C83E2B` engineering vermilion accent), `2px` chamfered corners, `10px` tonal slab joints, and aesthetic direction. Ask the user before departing from it. When reviewing or QA-ing UI, flag code that doesn't match DESIGN.md.
